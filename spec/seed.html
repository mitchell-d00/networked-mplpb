This page is written for a reader who has a copy of this directory and nothing else: no author, no original machine, possibly no software from the project at all.

1. Open it

Open index.html in any browser. Every link is relative, so the directory can live anywhere.

2. Check it is intact

_net/manifest.json lists every file with its SHA-256 hash. Compute the SHA-256 of each listed file with any tool you have (sha256sum, shasum -a 256, certutil) and compare. The corpus fingerprint is the SHA-256 of the file list written as compact JSON with sorted keys. A file that is present but not listed, or listed but different, means the copy is not the corpus it claims to be.

3. Decide what the copy is

A byte-identical copy is a mirror: same corpus ID, same fingerprint, nothing to change. If you intend to add or change anything, the copy becomes a new corpus and must say so:

  • descendant — a new corpus seeded from this one, owning a new domain;
  • fork — a new corpus that continues this one's domain under separate governance;
  • partial — a new corpus carrying only some spokes.

In all three cases: give it a new corpus ID in _net/corpus.json, set relation, record seeded_from (the old corpus ID and fingerprint), and append an event to _net/lineage.json whose prev field is the SHA-256 of the previous event. Seeded-from is lineage, not endorsement.

4. Make it a node

A node is a machine that carries one or more corpora and publishes a small signed description of them. The description lives outside every corpus, so a copied corpus never carries a machine's identity. See Network Rules.

5. Validate

The rules are in Validation Rules. The reference tool is python3 -m mplpb_net validate <dir>, but nothing in the rules depends on it.
