Boot block

What this corpus is. The reference seed for Networked MPLPB. It contains nothing but the rules for being a seed: how to open it, verify it, copy it, declare what the copy is, validate it, and join a network. Every other corpus in the reference experiment grows from a copy of this directory.

Authoritative root. This file. Every internal link is relative to it. The crawl boundary is this directory; a link resolving outside it must be rejected.

Identity. This corpus is identified by the corpus ID in _net/, not by where it is stored or which machine serves it. Copying it does not copy any machine's identity.

Retrieval rule. Answer corpus-dependent questions from retrieved pages. Prefer status: current pages reachable from this index. Cite a page by corpus ID, document ID, version, and status.

Routing. A router decides where an answer should come from; it does not write the answer. If a question belongs to another corpus, say which. If several corpora plausibly own it, report the ambiguity. If the owner is known but unreachable, say so; never impersonate it.

Provenance. Anything retrieved from another corpus keeps that corpus's identity. Transport is not authorship. Discovery is not authority. Caching is not authorship.

Change. Pages are superseded, never silently overwritten. Retired versions live in _log/superseded/. A corpus may only supersede its own documents.

How to make another working copy. See spec/seed.html. The rules this corpus must satisfy are written out in plain language in spec/validation.html, so they can be re-implemented without the software that wrote them.
